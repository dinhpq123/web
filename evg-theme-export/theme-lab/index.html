The date picker's calendar panel renders into a real portal at document.body in the live app. Its closed input box is genuinely themed in source (style.bundle.css:100149-100177) to match every other .form-control — reproduced faithfully above, not invented. Its open panel is genuinely unthemed — zero .ant-picker-dropdown rules exist anywhere in source — reproduced faithfully as antd's default blue. The third swatch is this package's proposed fix using the new datepicker.panelAccent/panelSelectedBg/panelTodayBorder tokens (all marked "status":"proposed" in tokens/evg-theme.tokens.json) — it is a recommendation to adopt, not something already true of EVG.
