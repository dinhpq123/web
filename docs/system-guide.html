HADIWA IOC — Tài liệu Kỹ thuật Hệ thống

Phiên bản v3.1 · Ngày cập nhật 13/03/2026 · Chi cục TT-PCTT TP. Hà Nội

🌐 Giới thiệu Hệ thống

HADIWA IOC (Intelligent Operations Center) là nền tảng quản lý, giám sát và điều hành tích hợp dành cho Chi cục Thủy lợi – Phòng chống Thiên tai TP. Hà Nội. Hệ thống cung cấp giao diện web đơn trang (SPA) với 25+ phân hệ nghiệp vụ.

🏗 Kiến trúc & Luồng khởi động

login.html
  └─ doLogin() → sessionStorage.set(qwc_user) → location.href = app.html

app.html  (loads scripts in order)
  ├─ js/data.js         — Mock data (stations, employees, reports...)
  ├─ js/config.js       — Feature flags, RBAC, presets, tab lists
  ├─ js/hub.js          — Orbital hub overlay
  ├─ js/pages/*.js      — Page render functions
  └─ js/app.js          — MENU defs, navigate(), buildSidebar(), DOMContentLoaded

DOMContentLoaded sequence:
  1. initRbac()         — Load user from sessionStorage, set permissions
  2. initTheme()        — Apply dark/light theme
  3. applyPreset()      — Apply feature/tab config for current preset
  4. buildSidebar()     — Filter menu by feature flags + RBAC
  5. showModuleHub()    — Show hub overlay if no savedPage (first login)
  6. navigate(page)     — Render first page
  7. updateClock()      — Clock ticker every 1s
Hub Trigger: Hub chỉ hiện khi localStorage.qwc_last_page chưa có giá trị (lần đầu đăng nhập). Để test hub, xóa key này trong DevTools → Application → LocalStorage.

🚀 Hub Module Launcher

js/hub.js · js/app.js L1342-1352

Cách hoạt động

Hiện khi localStorage.qwc_last_page rỗng (lần đầu).

10 phân hệ xếp vòng tròn, lọc theo feature flag.

Click phân hệ → dismiss + navigate(page)

Click logo sidebar → mở lại bất cứ lúc nào.

Thêm/sửa nhóm phân hệ

Sửa mảng HUB_GROUPS trong js/hub.js.

Mỗi group cần: id, label, page, features[], color, glow, icon.

features[] dùng để check isFeatureEnabled() — nếu tất cả tắt, nhóm bị ẩn.
